# SpecAutoAI

面向拉曼与 HPLC（高效液相色谱）曲线的分类建模工具。你可以在本机网页中整理曲线、训练模型、比较结果并导出图表，也可以让 AI 助手协助操作。

**第一次使用的顺序：安装并启动 → 准备数据 → 按需预处理 → 选择模型训练 → 查看结果。** 当前支持分类，例如区分样品种类；数值标签也会当作类别，不用于预测连续数值。

## 1. 安装与启动

### Windows：第一次安装

以下命令在 **PowerShell** 中运行。推荐 Python 3.12（64 位）；新环境默认使用 CPU，普通分类建模不需要显卡。

1. 安装 [Python 3.12](https://www.python.org/downloads/release/python-31210/)。已有 Python 3.12 或 Conda 环境时可以复用。
2. 打开 [qzt/skills 分支](https://github.com/fingercd/AutoAI/tree/qzt/skills)，点击 **Code → Download ZIP**，解压到固定目录，例如 `D:\SpecAutoAI`。该目录应直接包含 `run_classic.py`、`backend`、`static` 和 `skills`。仓库公开，无需 GitHub 登录。
3. 打开 PowerShell，进入实际解压目录，并为项目建立独立 Python 环境。独立环境用于把本项目依赖和其他软件隔开。

```powershell
# 将这里改为你的实际项目目录
Set-Location -LiteralPath 'D:\SpecAutoAI'
py -3.12 -m venv 'work\autoai-env'
$autoaiPython = Join-Path (Get-Location).Path 'work\autoai-env\Scripts\python.exe'
& $autoaiPython -m pip install --upgrade pip
```

4. 安装 CPU 版 PyTorch 和项目依赖。第一次下载可能较久，等待命令完成。

```powershell
& $autoaiPython -m pip install 'torch==2.5.1' --index-url https://download.pytorch.org/whl/cpu
& $autoaiPython -m pip install -r 'backend\requirements.txt' -r 'skills\autoai-research\requirements.txt' -c 'backend\constraints-verified.txt'
```

即使只用传统模型，当前程序也需要 PyTorch。**已有可用 GPU 环境时继续使用它**，不要执行上述 CPU 安装命令；GPU、Linux/macOS 和环境排错见[环境配置手册](skills/autoai-research/references/environment-setup.md)。

5. 检查依赖和导入情况；报告中 `ready=true` 表示这次环境检查通过。

```powershell
& $autoaiPython 'skills\autoai-research\scripts\check_environment.py' --python $autoaiPython --mode local --project-dir (Get-Location).Path --output 'work\environment-check.json'
```

6. 启动程序。浏览器通常自动打开，也可以手动访问 [本地页面](http://127.0.0.1:8000/)。网页服务和训练进程由启动器一起管理。

```powershell
& $autoaiPython 'run_classic.py'
```

使用期间保留 PowerShell 窗口。下次使用不需要重新安装，在项目目录执行：

```powershell
& '.\work\autoai-env\Scripts\python.exe' 'run_classic.py'
```

如果 `py` 命令不可用，使用已有 Python 3.12 的完整路径建立环境；具体操作见[环境配置手册](skills/autoai-research/references/environment-setup.md)。

## 2. 先看你的数据属于哪一种

| 你手上的文件 | 下一步 |
|---|---|
| 仪器导出的原始曲线 CSV，每个文件是一条曲线 | 进入“拉曼预处理”或“色谱预处理” |
| 每行是一条测量、每列是一个坐标点的建模 CSV | 检查标签和样品编号，直接进入“AI 建模” |
| Excel、转置表或多行表头，尚未整理为建模 CSV | 可让 AI 助手检查并整理；网页建模入口上传 CSV |

原始曲线的前两列应为数值：第一列是拉曼位移或保留时间，第二列是强度。原文件请保留，以便核对处理结果。

### 建模 CSV 长什么样

下面只演示文件格式，样品数和特征数不代表足够训练，也不代表真实实验数据：

```csv
Index,Label,Sample_ID,Name,400,401,402
1,甲类,A001,A001-1.csv,0.12,0.18,0.15
2,甲类,A001,A001-2.csv,0.13,0.17,0.16
3,乙类,B001,B001-1.csv,0.41,0.32,0.28
4,乙类,B001,B001-2.csv,0.40,0.34,0.27
```

| 列名 | 该填什么 |
|---|---|
| `Index` | 每条测量的编号，例如 1、2、3 |
| `Label` | 希望模型识别的真实类别，例如“甲类”“乙类” |
| `Sample_ID` | 实际样品编号；同一样品重复测量使用相同编号 |
| `Name` | 原始文件名，用于核对测量来源 |
| `400,401,402…` | 真实坐标，列内是该坐标对应的强度；HPLC 则使用真实时间坐标 |

上传前检查：

- 每行是一条测量；至少有两个类别，标签不能留空。
- 同一样品不能跨类别。同一样品测三次就用同一个 `Sample_ID`，不要编成三个独立样品。
- 当前要求各样品重复次数一致。缺测时先核对原始记录，不用复制行或填零补齐。
- 所有曲线使用同一组坐标；坐标必须唯一并按列递增，强度不能有空值、NaN 或无穷值。
- 独立测试集也必须逐点同轴，类别与主数据兼容，且不能包含主数据中相同的 `Sample_ID`。
- 用 Excel 编辑时保留坐标表头，不要改成 `特征1、特征2`；样品编号含前导零时按文本保存。最终另存为 **CSV UTF-8**。

## 3. 如何做数据预处理

预处理用于选择需要的曲线范围、处理拉曼基线或对齐色谱时间轴。已经整理好的建模 CSV 可以直接使用。训练时的标准化和 PCA 由程序在训练数据内完成，不要先在全部数据上计算。

### 拉曼曲线

1. 打开“拉曼预处理”，在“上传拉曼 CSV，可多选”中选择原始文件。
2. 选择“按行号范围”或“按 X 轴数值范围”。行号从 1 开始，首尾包含；X 轴范围按你的实验需求填写，不必照搬页面示例。
3. 基线校正先用默认 **arPLS**。基线是曲线中缓慢变化的背景，校正用于减少背景对峰形的影响。程序先截取范围，再校正基线。
4. 点击“生成整理 CSV”，查看原始曲线和校正后曲线，确认需要的峰保留下来且处理合理。
5. 下载建模 CSV，根据 `Name` 核对原文件，补齐 `Label` 和 `Sample_ID`，保存后进入“AI 建模”。

### HPLC / 色谱曲线

1. 打开“色谱预处理”，选择一个或多个原始 CSV。页面自动显示各文件点数和状态。
2. 同批文件的有效点数必须一致且至少为 2；出现异常文件时先检查它的导出范围或缺失数据。
3. 选择按行号或保留时间截取。行号范围首尾包含，终止行留空时使用检测到的完整范围。
4. 默认开启“启用线性插值”：把曲线映射到服务端配置的固定时间轴，当前默认覆盖 0–50 分钟，点数来自当前批次。先确认该时间范围符合你的实验；插值不等于自动校正峰的保留时间漂移。
5. 若关闭插值，会保留所选原始坐标与强度，但多文件所选坐标必须完全一致，否则不能导出。
6. 点击“生成整理 CSV”，检查预览，下载后补齐 `Label` 和 `Sample_ID`，再进入“AI 建模”。

色谱预处理不执行消负或面积归一化。一次处理生成一个统一的建模 CSV。

## 4. 如何选择模型并开始训练

### 常用模型怎么选

页面提供以下 9 个分类模型。没有一种模型对所有数据都最好；建议先用传统模型建立基线，再按数据量和目标增加比较。

| 模型 | 大致怎么工作 | 什么时候可以尝试 / 注意事项 |
|---|---|---|
| **PLS-DA** | 提取与类别有关的少数潜变量，再分类 | 常作为高维光谱、小样品数据的起点；成分过多可能过拟合 |
| **sPLS-DA** | 在 PLS-DA 中加入稀疏约束，每个成分保留部分变量 | 想尝试减少参与分类的变量时；本版不提供变量重要性展示 |
| **PCA-LDA** | 先用 PCA 压缩曲线，再做线性判别 | 希望获得较简单的线性分类基线时；PCA 保留大方差方向，不保证保留全部分类信息 |
| **Elastic Net** | 带 L1/L2 正则化的逻辑回归 | 类别关系较接近线性、特征高度相关时；正则化帮助限制过拟合 |
| **SVM** | 用支持向量寻找分类边界，快速模式使用 RBF 核 | 小样品、高维且可能非线性的曲线；注意标准化 |
| **PCA-SVM** | 先 PCA 降维，再用线性 SVM 分类 | 想比较降维后的分类基线时；它与原始特征上的 RBF-SVM 不同 |
| **Random Forest** | 多棵决策树共同分类 | 可以补充非线性基线；特征很多时仍应留意过拟合和耗时 |
| **XGBoost** | 逐步组合决策树来改善分类 | 想增加树模型对照时；数据较少时不能只看训练成绩 |
| **1D-CNN** | 用一维卷积学习相邻曲线点的局部模式 | 独立样品较多、有计算预算时再尝试；通常训练更慢，也需要关注过拟合 |

**首次尝试可选 PLS-DA 和 SVM。** 希望比较降维方案时加入 PCA-LDA 或 PCA-SVM；想尝试稀疏变量建模时加入 sPLS-DA。一次多选模型，会使用固定的数据划分建立同批次比较。

### 按页面完成一次建模

1. 进入“AI 建模”，点击“加载数据集”，上传整理好的建模 CSV。先核对样品数、测量数、类别和曲线预览；有独立测试数据时点击“加载独立测试集”。
2. 在“模型架构（可多选）”中选择模型。
3. “训练方式”先选 **快速训练（单方案、一次验证）**，“特征处理”先选 **全特征**。传统模型最多尝试三组参数，用验证集选定后重训。
4. 保持默认训练 / 验证 / 测试目标比例 **8:1:1**。所有划分按 `Sample_ID` 整组进行；数据少时，为保证各分区包含每个类别，实际比例可能调整。普通三分区划分每类至少需要三个独立样品。
5. “高级选项”中的标准化先保持 **zscore（Z-score）**，即用训练数据计算各特征的均值和尺度。随机种子默认 42，用于复现划分和训练中的随机步骤。
6. 点击“开始训练”，等待当前训练完成，再查看“建模结果”或多模型比较。训练记录可用于重新打开历史结果。

三类数据的作用：**训练集**用于拟合模型，**验证集**用于选择参数或停止训练，**测试集**用于报告选定模型在未参与拟合的数据上的表现。

### 什么时候改用其他设置

| 设置 | 用途与注意事项 |
|---|---|
| **Binning 5/10/20** | 将相邻 5/10/20 个点取均值，减少特征数量；可能压缩噪声，也可能损失窄峰细节 |
| **PCA 90/95/99%** | 保留累计解释方差达到对应比例的主成分；该比例不是分类准确率 |
| **完整比较** | 比较全部适用特征方案，传统模型做分组五折选参，耗时更多；每个搜索池每类至少需要五个独立样品 |
| **逐个留出样品评估** | 每次留出一个真实样品测试，其余样品重新建模；所有外层预测合并为 OOF 结果，日常快速尝试可先关闭 |
| **独立测试集** | 使用另外采集、未参与方案选择的数据做最终测试；主数据默认按 8:2 分为训练和验证 |

PLS-DA、sPLS-DA、Elastic Net、SVM、Random Forest、XGBoost 支持七种特征方案。**PCA-LDA、PCA-SVM 自带 PCA，不再叠加外层 PCA；1D-CNN 保留曲线顺序，也不使用 PCA 输入。** 这三个模型支持全特征和三种 Binning。多选模型时，快速训练只能选择它们共同支持的特征方案；完整比较则分别运行各模型适用的方案。

## 5. 如何看结果和导出文件

先看测试成绩，再检查各类别是否都能识别。模型在训练集上成绩很高，只能说明它拟合了训练数据。

| 指标 / 图表 | 怎么读 |
|---|---|
| **Accuracy（准确率）** | 全部测试测量中预测正确的比例；多数类别可能主导这个数值 |
| **Balanced Accuracy（平衡准确率）** | 各类别 Recall 的平均值；类别数量不均衡时更有参考价值 |
| **Macro-F1（宏平均 F1）** | 各类别 F1 的平均值，每类权重相同；兼顾查准率和召回率 |
| **Recall（召回率）** | 某类真实测量中，被正确识别为该类的比例；低 Recall 表示漏掉较多 |
| **Precision（查准率）** | 被预测为某类的测量中，真正属于该类的比例 |
| **混淆矩阵** | 对照真实类别和预测类别；看轴标签，重点检查哪些类别相互混淆 |
| **预测明细** | 逐条查看真实类别、预测类别和类别概率；概率不代表预测一定可靠 |

类别不均衡时结合 **Balanced Accuracy、Macro-F1 和各类别 Recall** 判断，不只看 Accuracy。测试集很小或包含重复测量时，也要结合独立样品数理解成绩。

多模型比较页可查看总体表现、类别指标、样品预测、特征方案以及参数和划分；支持图表 PNG/SVG、CSV、ZIP 归档与预测 Excel 下载。Excel 包含“预测类别”和“预测概率”两个工作表。未运行、失败或不适用的方案会明确标记，不当作零分。

最佳参数与特征方案由验证数据选择。反复看测试成绩再修改方案，会让测试数据参与选择；最终报告建议再使用未参与选择的独立测试集。当前不提供 ROC 曲线、ROC-AUC 或变量重要性展示。

## 安装 AI 助手技能

网页可以独立使用；需要 Codex 帮你检查 Excel/CSV、推荐设置或执行建模时，再安装此技能。两种方式任选其一。

### 手动安装

1. 保留前面下载的完整项目目录，将其中 `skills/autoai-research` **整个文件夹**复制到 Codex 技能目录。
2. Windows 默认目录为 `%USERPROFILE%\.codex\skills\`，Linux/macOS 为 `~/.codex/skills/`；设置了 `CODEX_HOME` 时使用其下的 `skills/`。
3. 确认最终有 `autoai-research/SKILL.md`。下一轮对话告诉助手项目实际位置，例如 `D:\SpecAutoAI`，它会检查环境并配置本机运行路径。

### 让 Agent 安装

把这段话发给 Codex：

> 请从 GitHub 的 fingercd/AutoAI 仓库 qzt/skills 分支下载完整项目，将 skills/autoai-research 安装到我的 Codex 技能目录。复用已有项目；安装目录已存在时先检查，更新时保留本机 runtime.json。按环境配置手册检查依赖，发现问题先告知再修复，验证通过后配置本机运行路径，并告诉我如何开始使用。

完整项目用于本地计算，请保留。本机 `runtime.json` 记录本机路径，不从其他机器复制。维护细节见[技能使用说明](docs/autoai-research-skill.md)。

### 用 AI 助手建模

**先检查数据并推荐方案：**

> 使用 $autoai-research 检查 D:\数据\光谱.csv，说明数据情况，推荐一个快速分类方案，先不运行。

**接受助手已经给出的方案：**

> 按推荐方案开始。

**明确要求直接运行：**

> 使用 $autoai-research 检查 D:\数据\光谱.csv，推荐快速分类方案，请直接跑。

普通建模请求会先汇报数据、模型和设置，集中询问一轮选择；回复“按推荐方案”即可开始。“请直接跑”会跳过这轮设置询问，但缺少真实标签或样品分组时仍需要补齐信息。首次使用发现环境问题时，助手会先告知，再按配置手册修复。

## 常见问题

- **页面打不开**：确认启动命令仍在运行，查看 PowerShell 中的提示。服务已启动时直接访问本地页面，不要在同一端口重复启动。
- **找不到 Python 或缺少依赖**：确认安装和启动使用同一个解释器，参照[环境配置手册](skills/autoai-research/references/environment-setup.md)处理。
- **提示标签、重复次数或坐标不一致**：回到原始记录核对；不要为了上传成功随意改标签、补零或复制测量。
- **提示样品不足**：查看提示中的具体类别和数量；完整比较需要更多独立样品，可以先使用快速训练。重复测量不能替代独立样品。
- **训练很慢**：先选一两个传统模型，使用快速训练，暂不开启留一样品评估；完整比较和深度模型会增加计算量。
- **新增模型没出现或一直排队**：完成已有任务后重新启动网页服务和 Worker，再刷新页面。仅刷新浏览器不能让后台加载新代码。
