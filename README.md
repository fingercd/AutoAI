# AutoAI 分类研究 Skill

## 安装

复制下面这段话给 Codex、Claude Code 等支持 Skill 的 Agent：

```text
请从 https://github.com/fingercd/AutoAI 的 qzt/skills 分支下载完整项目，将 skills/autoai-research 安装到当前 Agent 的技能目录。按技能中的环境配置手册检查并配置依赖，验证通过后保存本机运行路径。复用已有项目和可用环境，保留用户改动与本机配置，不中断已有训练。

使用时保持两次对话：第一次检查文件，说明数据情况、推荐模型和训练设置，把需要确认的问题一次问完并等待回复；第二次收到选择后，告知最终模型与参数设置，直接训练并交付结果，不重复确认是否开始。不要猜测真实标签或样品分组，不向用户展开内部接口与系统诊断。
```

## 使用例子

### 1. CSV 快速分类

第一次：

> 使用 $autoai-research 检查 D:\数据\光谱.csv，推荐快速分类方案，需要确认的问题一次问完，等我回复后训练。

第二次：

> 按推荐方案开始。

### 2. Excel 整理与建模

第一次：

> 使用 $autoai-research 检查 D:\数据\拉曼.xlsx 的“测量数据”工作表。“类别”列是标签，“样品编号”列是样品分组，同一样品测了三次。提出整理和分类方案，需要确认的问题一次问完，等我回复后执行。

第二次：

> 按推荐方案整理并训练，保留原始文件。

### 3. 多模型比较与独立测试

第一次：

> 使用 $autoai-research 检查 D:\数据\主数据.csv 和 D:\数据\独立测试.csv，比较 PLS-DA 与 SVM。推荐训练设置，需要确认的问题一次问完，等我回复后运行。

第二次：

> 按推荐方案运行，独立测试集只用于最终评估，并导出预测 Excel。
