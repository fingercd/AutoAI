# AutoAI 分类研究 Skill

让 AI 助手检查拉曼或 HPLC 的 Excel/CSV 文件，推荐分类模型与训练设置，并完成训练和结果交付。

## 安装 AI 助手技能

下载并配置此 Skill，请打开下面的文档，将其中的安装提示词复制粘贴给你的 **Codex、Claude Code 或其他支持 Skill 的 Agent**，让它完成安装与环境配置。

**[打开安装提示词，复制给你的 Agent](docs/install-autoai-research.md)**

## 三种使用方式与例子

安装完成后，在对话中指定 `autoai-research` 技能、文件位置和目标即可。Codex 可使用 `$autoai-research`；其他工具按其技能调用方式使用同名技能。将下面的示例路径换成你的实际文件路径。

**保持两次对话：**第一次，助手检查文件，说明已知的数据情况、推荐模型与设置，并把需要你选择或补充的信息一次问完；第二次，你接受推荐或给出修改，助手说明最终模型和参数设置后直接训练，等待完成并交付结果，不再追问是否开始。以下助手回复仅示意，实际推荐与参数根据文件确定。

### 1. 检查建模 CSV，让助手推荐方案

适合已经有类别和真实样品编号、希望先做一次快速分类的文件。

**第一次对话——你：**

> 使用 $autoai-research 检查 D:\数据\光谱.csv，告诉我这份数据是什么情况，推荐一个快速分类方案。模型、特征处理和评估方式需要我选择的内容一次问完，等我回复后再训练。

**助手：**读取文件并说明独立样品数、测量数、类别和重复关系；例如推荐 RBF-SVM、全特征、Z-score 标准化、按样品分组的 8:1:1 留出评估和 seed 42，参数由验证集选择。把尚未指定的选项集中列出，等待你的选择。

**第二次对话——你：**

> 按推荐方案开始。

**助手：**告知最终模型和设置，直接完成训练，提供实际划分、选定参数、测试成绩和结果文件。

### 2. 整理 Excel，再完成分类

适合尚未整理成建模 CSV 的拉曼或 HPLC 表格。你可以在第一条消息里说明工作表、类别列和样品编号列。

**第一次对话——你：**

> 使用 $autoai-research 检查 D:\数据\拉曼.xlsx 的“测量数据”工作表。每行是一条测量，“类别”列是标签，“样品编号”列表示真实样品，同一样品测了三次。请检查并提出整理和快速分类方案，缺少的信息一次问完，等我回复后再整理和训练。

**助手：**核对表格结构、类别、分组和坐标，说明准备如何整理并推荐模型、特征处理、标准化和评估方式；如有需要确认的列或处理范围，与设置选项一起提出。

**第二次对话——你：**

> 按你提出的整理和训练方案执行，保留原始文件。

**助手：**应用已确认的映射，生成建模 CSV，告知采用的模型与参数设置，完成训练并交付整理后的文件和结果。

### 3. 指定模型，用独立测试集比较

适合希望比较指定模型，并用另外采集的数据检验表现的任务。

**第一次对话——你：**

> 使用 $autoai-research 检查 D:\数据\主数据.csv 和 D:\数据\独立测试.csv，比较 PLS-DA 与 SVM。先核对两份文件是否适合建模，建议快速训练的特征处理、标准化和主数据划分，集中问我一轮设置，等我回复后再运行。

**助手：**核对坐标、类别和样品是否重叠；建议全特征、Z-score、主数据按样品 8:2 划分训练与验证、seed 42，独立测试集用于最终评估。说明两个模型的参数由验证集选择，集中询问其余适用选项。

**第二次对话——你：**

> 按这个方案运行两个模型，独立测试集只用于最终评估，并导出预测 Excel。

**助手：**说明最终设置，完成两个模型的训练和比较，提供独立测试成绩、各类别表现、实际选定参数及预测 Excel。

如果文件缺少真实标签、样品分组或必要坐标，助手会在第一次对话集中指出；第二次回复时一并补齐这些信息，才能继续训练。
