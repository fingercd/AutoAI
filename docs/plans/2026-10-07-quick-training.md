## 固定配置与行为

- `experiment_version=word-0904` 新训练默认 `training_profile=quick`、`feature_scheme=full`。
- 快速模式只训练用户选定的一种特征方案；其他方案记录 `not_run` 和原因，不生成虚假分数。CNN 的 PCA 仍不适用。
- 五种传统模型最多三套参数，每套在当前训练样品上拟合，用当前验证样品的 Balanced Accuracy 选优。同分保留固定候选顺序，不使用测试数据。
- 选定后在训练与验证合并数据上重训一次；训练、验证审计复用获胜候选模型，不另行拟合。一般三候选加一次重训，共四次拟合。
- PLS-DA 潜变量候选 1/3/5（只保留当前训练维度可行的项）；逻辑回归 C=0.1/1/10，固定 l1_ratio=0.5；SVM 固定 RBF、gamma=scale，C=0.1/1/10；随机森林固定 500 棵树、叶子最少 1、max_features=sqrt，深度 None/5/10；XGBoost 固定 100 棵树、min_child_weight=3，深度 2/3/5，其余采用原完整网格的固定值。
- CNN 只训练所选方案，保留 AdamW、CrossEntropyLoss、最多 200 epochs、调度、早停和最佳验证损失 checkpoint。外部最终重训继续锁定主数据选择的 epoch。
- 普通划分默认一次建模；逐样品留出仍是用户主动选择，四种划分及自定义比例继续支持。
- 用户主动选择 `training_profile=full` 时保留原完整网格、多方案、分组五折。未声明实验版本的旧兼容 API 保持原行为；历史结果不重算。
- `/api/models.training_scheme` 公布默认模式、特征选择、候选数量。配置及模型元数据记录实际模式，结果明确区分一次验证与五次平均。
- Worker 执行能力版本为 `run-artifact-manifest-v2-quick-training-v1`，结果 Manifest 仍为 v2；新 Web 拒绝旧 Worker，前端拒绝缺少新选项能力的后端，避免快速配置被旧进程忽略。
