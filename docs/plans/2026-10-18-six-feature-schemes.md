## 本轮明确需求与解释

用户要求按老师聊天和参考热图直接实现。经典建模页移除 Full，提供 BIN3、BIN6、BIN12、PCA5、PCA10、PCA15；PCA 数字按固定主成分个数解释，不按方差百分比解释。保持现有单选交互，每次只运行选中的一种，不自动扩大为六方案全跑。恢复按独立 Sample_ID 留一交叉验证的可选开关；不增加回归模型或 MAE，不改变模型网络、候选参数、早停与优化器。

## 处理与兼容边界

- BIN3/6/12：每 3/6/12 个相邻点取均值，保留不足整箱的尾部，再拟合 Z-score。
- PCA5/10/15：先拟合 Z-score，再提取固定 5/10/15 个主成分。若当前训练记录数或特征维度不足，明确报错，不裁剪主成分数、不偷偷换方案。
- 标准化与 PCA 只在允许的训练数据上拟合。传统模型选参阶段只用 Train；锁定后在 Train+Valid 重新拟合。Test 始终不参与拟合或选优。
- 学生页面默认 BIN3、quick；Full 与旧 BIN5/10/20、PCA90/95/99% 保留为兼容 API 和历史结果能力。旧 `training_profile=full` 仍执行原七/四方案，不把旧请求静默改成新六方案。
- 后端能力目录声明学生可见方案与默认值，前端不再自建另一套方案表。CNN 仍不接受 PCA，冲突时提示并拒绝提交。
- 默认仍为分组 holdout 8:1:1；启用 CV 后每折留一个 Sample_ID，其余 8:2。外部 Test 可与 CV 同时使用，此时主数据 OOF 仅作审计，外部 Test 为主指标。
- CV 勾选在当前标签页记忆，数据集上传或重复渲染不改写它；不恢复旧版本隐藏设置的值。划分比例及高级参数仍隐藏。
- 新结果特征表/热图按实际方案组展示六行；历史七行保留。未运行、不适用、失败保持原因，不能补零或补造比较数据。
- 升级 Worker 能力版本；现场 Web/Worker 仅在无 queued/running 任务时同步更新，不强制打断用户训练。

## 验收安排

1. 数值测试：三种均值 Binning（含尾部）；固定 PCA 个数及 sklearn 等价性；训练不足明确失败；Test 变化不影响训练参数；旧方差 PCA 数值语义保留。
2. 训练测试：六方案 quick 请求；四种评估口径、分组防泄露、PCA 逐折拟合、CNN 三种 Binning/PCA 拒绝；结果六行及历史七行并存。
3. 页面测试：六项无 Full、默认 BIN3、CV 四场景、刷新记忆、单/多模型请求、PCA/CNN 冲突、状态恢复/停止/比较/导出回归。
4. 真实 `测试.csv` 固定数据验收：PLS-DA 六方案 quick 留出验证，至少一次新方案 Sample_ID 留一闭环，并与旧实现/独立 sklearn 数值基准核对；所有实际训练通过 SwanLab 在线记录并回读。日志保存 commit/dirty、配置、seed、数据哈希、命令、环境与产物校验，不进入 Git。
5. 运行专项测试、完整 `backend/tests`、compileall、前端语法检查和浏览器核验。结果在完成后追加。
