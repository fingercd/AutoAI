# 模型 × 特征处理 × 留一折：组合训练与展示

本轮用户明确要求特征多选、模型多选与按样品留一的乘法关系，以及清晰的合并展示。既有未提交的六方案实现保留，本轮在其基础上扩展。

## 执行单位

- 每个有效 `(model_type, feature_scheme)` 组合创建一个独立 Run，仍 `repeat_count=1`。普通留出每个 Run 一个外层划分；留一每个 Run 完成 N 个 Sample_ID 外层折。
- 理论组合 M×S；CNN×PCA 等不支持的组合明确列为“不适用”，不创建伪 Run，不替换特征方案。实际外层折任务为有效组合数×N；这是外层折计数，不是参数搜索/最终重训的精确 fit 次数。
- 同一批次所有组合共用数据快照、split_seed 与相同样品分组；每折独立拟合标准化、PCA、模型与选参。不同方案不共享已拟合的变换。
- 请求顶层增加 feature_schemes；config 不再混入单个 feature_scheme。新增组合批次要求 word-0904/quick；旧单方案 API、旧批次与历史重复记录语义保留。
- 保持现有 SQLite 事务与表结构：batch_model_order 表示新批次的组合顺序，模型/方案身份始终分别保存；不把组合伪装成新的 model_type。

## 结果组织

- 进度按组合列出模型、特征处理、状态、当前折/总折；同时显示理论组合、不可用组合、有效组合和总外层折任务数。
- 对比总览用“特征处理×模型”矩阵显示四项可切换主指标；CV 取 pooled OOF，外部 Test 取直接外部测试。不同方案不平均、不丢弃同模型的其他方案。
- 展开单个特征处理后沿用原总体/类别/样品/参数页：每个组合可跳转独立 Run；逐折参数与测试样品按需展开，普通留一不虚构全局最佳。
- 全局先校验所有成功组合的数据快照、划分 digest、测试样品集与标签映射；不一致则禁止公平比较。部分失败、未完成和不适用保留原因，不填零。
- 图表请求可指定 feature_scheme；ZIP 的单方案图文件名带方案前缀，合并矩阵与 CSV 同源。预测 Excel 每列为“模型 · 特征处理”，不得覆盖同模型不同方案。
- 停止、刷新恢复、归档、权限、Manifest 和公开下载校验沿用现有流程。只在空闲时更新现场 Web/Worker。

## 验收

验证 2×2 组合、含 CNN/PCA 不适用组合、所有选项为空/重复/无效、50 Run 限制、事务性入队、同 seed、公平比较、四种评估口径、CV OOF/逐折归属、状态恢复/停止和全部导出。真实 `测试.csv` 跑 2 模型×2 特征的 holdout 与 24 折 LOO：各 4 个 Run，LOO 共 96 个外层折。SwanLab 在线记录并回读；源代码 dirty、配置、数据哈希与日志保留在隔离输出目录。

## 同轮用户纠正：样品编号自然排序

用户指出样品正误热图及详情表出现 1、10、11、…、2 的字符串顺序。比较投影复用 parsers.natural_sort_key，前端详情复用 ui-utils.naturalCompare；绘图按原索引自然排序后读取同一位置的正误值，不能只改标签而错配预测。图像与对应 CSV 同源，图集版本升级 comparison-figures-v7，使旧归档从已校验的预测产物重建。不重命名 Sample_ID，不改变训练/划分或重训。专项覆盖 1/2/3/10、S1/S2/S10、筛选与分页索引以及预测/详情配对。
