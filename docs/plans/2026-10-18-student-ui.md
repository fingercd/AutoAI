# 经典学生界面：保持 UI，只做交互减法

## 依据与范围

用户在 2026-10-18 要求按“科研绘图方案”对话的最终版本修改，并以主分支覆盖本地代码基线、做好 Git。最终确认是不重做 UI，只减少按钮和参数。本轮从 `origin/master` 的 `a8835e7` 开始，不合入 `qzt/skills` 上的其他功能；该分支仍保留。

不新增绘图引擎、ROC/PR、解释性、模型或训练算法，不改变原有布局和五个导航入口。

## 界面行为

| 页面 | 当前行为 |
| --- | --- |
| AI 建模 | 保留主/独立数据集加载、模型多选、特征处理、开始/停止训练和原曲线预览 |
| 训练配置 | 仅全特征、Binning 10、PCA 95%；从后端能力中过滤这三项，不伪造不可用能力 |
| 隐藏设置 | 训练方式、比例、CV、高级参数；保留共享脚本依赖的 HTML ID，不再绑定这些控件的交互 |
| 拉曼 | 保留文件、范围选择、预览与 CSV；固定 arPLS，不读隐藏的自定义算法值 |
| HPLC | 范围、点数检查与线性插值开关不变 |
| 结果 | 图表与指标不删；原参数审计已默认折叠，新增任务 ID/模型 ID/数据指纹折叠详情，按 ID 查询也折叠 |
| 记录 | 不显示 Run ID 列和复制 ID；保留查看、当前状态可用的停止或删除，以及所属对比入口 |

Binning 10 和 PCA 95% 采用最终对话前一版原型建议，并在下拉名称直接说明，不新增可调参数。不支持 PCA 的 CNN 与 PCA 同时选择时保留选择、显示冲突并阻止提交，不能静默换为全特征；检查覆盖整个多模型批次，不只首个模型。

## 请求默认值与科研边界

- 新网页任务固定 `experiment_version=word-0904`、`training_profile=quick`、`normalization=zscore`；训练 epoch、batch、seed 等继续读取后端 `training_scheme.defaults`。
- 无独立 Test：`stratified_holdout`、8:1:1；有独立 Test：`external_test_holdout`、主数据 8:2，不提交内部 `split_test`。
- 网页请求不读取旧会话 CV/比例、隐藏标准化或 seed 值；单模型与多模型批次使用相同默认策略。Batch 的 `base_seed` 来自已构造的配置，而非隐藏输入框。
- Sample_ID 分组、防泄露、Test 口径、后端权限、Manifest、下载、进度恢复和停止机制不变。
- 后端 quick/full、七/四特征方案、四种评估模式与自定义比例能力均保留，历史任务仍按原口径展示。
