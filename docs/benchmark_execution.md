# 分类选模实验执行与结果导航

最近核对：2026年10月15日。实验执行合同由对应用户批准的冻结版本决定。此文是导航，不授权新的训练、LLM调用、协议更改或部署。

## 已完成的三类工作

1. **历史完整实验。** 第四版及第五版结果保留。第五版统一候选验证与最终评价的Sample_ID概率聚合规则，并明确选模目标；正式报告114项任务，另15项开发任务。默认参数与最多三套参数属于不同训练预算。见[第五版统计](research/history/benchmark-20261012-statistics.md)和[早期复盘](research/history/benchmark-20261011-review.md)。
2. **七模型初版知识验证。** 129项任务，七模型903项同条件成绩：873项复用编号01默认参数记录，只新增30次简单一维卷积。相同任务的七模型使用同一样本安排，不混入多轮汇总。初版平衡准确率69.2747%，同七模型均匀随机期望65.0502%。见[执行计划](research/knowledge-20261013/execution-plan.md)和[报告](research/knowledge-20261013/report.md)。
3. **优势知识修订复验。** 同903项矩阵，新做129次模型选择、无分类重训；实际129次请求全为合法原始JSON，未追加格式重试。平衡准确率71.5062%，高于随机6.4560个百分点；但主成分降维仍0次选择，基因任务均值下降。见[完整报告](research/knowledge-20261014/report.md)。

不同阶段不能直接拼成知识消融：任务数、模型菜单、输入信息和多轮统计规则不同。七模型知识来自同批任务的回看，不能宣称独立泛化。历史方法代号仅在归档统计里保留，新说明用具体行为描述。

## 当前代码入口

`scripts/benchmark.py` 提供 prepare、run、resume、status、report。执行前按对应版本检查批准、实际数据和分区、合法模型、冻结参数、代码、LLM资产、资源和记录渠道。准备与恢复不等于授权新训练，缓存不得跨不匹配的协议静默复用。

通用产品流程与独立知识选模研究脚本分开；研究的真实入口源码见[只读参考](research/execution-reference/README.md)，不可直接复制旧批准状态启动新任务。

## 记录、资源和数据边界

历史完整实验的SwanLab豁免只适用于当时明确批准的范围；两轮知识选模和30次补测均完成在线记录与云端回读。不得把历史豁免泛化为新实验默认。

GPU使用前重新核对资源归属；历史共享授权不能自动覆盖新的任务或其他GPU。分类模型的拟合数、缓存复用、参数候选数、最终重训与LLM请求数分别核算。

Git只保留可共享报告、参数、知识和汇总结果。原始数据、分区样本名单、逐样本预测、权重、数据库、日志及大型归档在服务器work内保留，不进入公开仓库。完整历史执行描述见[发布前历史版本](research/history/execution-description-before-20261015.md)。
