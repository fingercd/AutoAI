# 给 Agent 的 AutoAI Skill 安装提示词

将下面整个文本框复制粘贴给你的 Codex、Claude Code 或其他支持 Skill 的 Agent。它会根据当前工具的技能目录安装 `autoai-research`，并检查、配置本机环境。安装完成不代表已开始训练；使用示例见 [README](../README.md)。

```text
请为当前使用的 Agent 安装并配置 autoai-research Skill。

来源是公开 GitHub 仓库 https://github.com/fingercd/AutoAI，使用 qzt/skills 分支，技能路径为 skills/autoai-research。

请自行完成以下工作：
1. 检查已有项目和技能安装。已有完整 AutoAI 项目时核对来源与版本并优先复用，保留用户改动；否则下载完整项目到持久目录。项目源码用于本地计算，不能只下载 SKILL.md，也不能安装后删除项目。
2. 根据当前工具实际支持的 Skill 目录安装整个 skills/autoai-research 文件夹，保持目录名 autoai-research，并确认该目录直接包含 SKILL.md。Codex 按其当前技能安装规则处理；Claude Code 或其他工具按各自的技能发现规则处理，不直接套用 Codex 的安装目录。需要核对规则时查询该工具的官方说明。如果当前工具不支持 Skill，请说明具体限制，不声称已安装成功。
3. 更新已有安装时保留本机 runtime.json 和用户自定义文件，不复制其他机器的运行路径或缓存，不覆盖用户已有改动。
4. 阅读安装后的 SKILL.md 及 references/environment-setup.md，检查本机 Python、技能依赖和完整项目依赖。复用健康环境；发现问题先简要告知准备采取的修复，再补齐依赖或建立专用环境，避免破坏其他项目。按照手册复查依赖、导入和计算服务，不把文件复制完成或 pip 安装成功当作环境验收通过。
5. 检查通过后，将本机实际项目目录和 Python 解释器绝对路径保存到技能根目录的 runtime.json，仅保存 project_dir、python，不写入密钥或凭据。确认当前工具可以发现该技能；若需要重新加载或新开对话，明确告诉我。
6. 安装与检查期间不上传我的数据，不提交训练，不提交或推送项目改动，不中断已有服务或训练。最后只简要说明技能是否可用，以及如何调用；未通过的步骤如实说明。

之后使用该技能时，请保持两次对话：
第一次，根据我指定的文件和目标检查数据，说明你知道什么、推荐什么模型及训练设置，把所有适用的选择和真正缺少的信息一次问完，然后等待我回复，不提交训练或执行预处理。
第二次，我接受推荐或补充设置后，你说明最终模型、特征处理、标准化、评估方式和参数选择方式，直接完成整理、训练和结果交付，不再重复确认是否开始。真实标签或样品分组不能靠猜测补齐。
普通回复围绕数据、方案、待确认问题和结果，不展开内部系统编号、接口或进程诊断。
```
