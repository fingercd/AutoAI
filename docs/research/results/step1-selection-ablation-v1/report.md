# 第一步：同条件知识选模对照结果

日期：2026年10月23日。

## 结论

在同一批129个已见任务上，有知识选模的平均平衡准确率为 **71.5062%**，无检索知识为 **59.2530%**，相差 **+12.2532 个百分点**。
本批七种固定策略中最高的是逻辑回归，为 **68.9192%**；知识组比它高 **+2.5871 个百分点**。这个“最高”是表内描述，不是事先挑定的冠军基线。
知识组相对无知识组：**73项提高、27项持平、29项下降**。本轮支持保留当前知识，但不证明复杂自主Agent的必要性，也不是独立泛化验证。

## 执行与评价口径

- 用户确认的协议：[step1-selection-ablation-v1](../../step1-selection-ablation-v1.md)。
- 129个任务，每任务两次单模型选择，共258次真实请求；258次均合法，额外请求0，未知用量0。
- Qwen3.5-9B原始权重；node2 GPU 1（V100 32GB），float16。GPU 0上的其他用户任务未动，其他卡未使用。
- 两组使用同一服务、系统提示、模型候选顺序和训练摘要；无知识组仅把检索知识列表置空。temperature=0、关闭thinking、max_tokens=1024。
- 有知识和无知识都是本轮新调用，不拿旧调用直接充当对照。每任务交替哪组先执行。
- **新增分类拟合0**。选择完成后复用冻结七模型成绩；不读取Test来决定模型，不通过多个候选的验证竞争选赢家。
- 报告任务等权的测试平衡准确率；随机期望是每任务七个冻结成绩均值，不是集成或新增随机训练。
- 原矩阵的建设成本不属于本轮新增成本；零重训不表示真实部署训练免费。
