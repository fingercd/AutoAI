# 可共享实验结果与复核口径

这里保存的是实验产生的结果，不是实验原始数据。所有分数以0到1保存，中文报告换算为百分比；百分点差为两个分数之差乘100。

- `seven-model-scores.json`：129个任务、每任务七模型的903项成绩、冻结参数、来源类别和结果摘要。每任务仅编号01的一次样本安排；新增卷积与其他模型同条件。
- `initial-summary.json`、`revised-summary.json`：两轮汇总；`initial-selections.json`、`revised-selections.json`：逐任务所选模型、简短理由和成绩。
- `previous-vs-revised.json`：两轮对应变化。修订版113任务改选，58任务平衡准确率提高、25并列、46下降。
- `initial-knowledge.json`、`revised-knowledge.json`：实际冻结的人工知识内容、条件和排序参照。不是自动学习出来的知识生成程序。
- `revised-prompt-contract.json`：实际系统提示、推理设置、候选模型、训练摘要字段名和检索数量限制；不公开逐任务训练数据画像数值。
- `*-call-accounting.json`、`*-audit.json`、`*-cloud-verification.json`：调用、结果一致性和SwanLab核验摘要；不是原始运行日志。
- `benchmark-20261012-summary.json`：历史完整实验的聚合结果、比较和覆盖，用于理解演进。其114项正式任务、每任务可用模型与多轮规则不同，不能直接和当前129项统一七模型的均值相减作知识消融。
- `provenance.json`：来源代码和原文件指纹。完整原件在服务器保留。

当前七模型随机期望：对每任务七个模型的同一指标求均值，再对129任务等权平均。不新增随机训练，不平均模型预测，不使用最高测试成绩。数值并列容差为1e-12。

最新两轮使用的数据划分、候选默认参数与推理设置保持不变；修改的是人工知识正文及两个Train描述，不能分别估计它们的独立贡献。测试分数未作为当前任务输入直接提供给大模型，但知识构建已经回看过这些任务，因此仍是内部探索。

不包含：原始特征矩阵、逐样本标签或编号、逐样本预测或概率、训练/测试样本名单、模型权重、数据库、凭据、SDK缓存和原始日志。记录中的数据与分区指纹用于绑定版本，不提供数据本身。
