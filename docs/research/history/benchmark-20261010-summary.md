# 小样本训练 Agent：第一轮完整实验报告

核对日期：2026-10-11。正式效果统计覆盖全部 **114 个锁定任务**；15 个开发任务用于验收和确定固定模型，另有两次动态处理功能验收。所有保留作业已完成，未记录到冻结版本的训练失败。

当前冻结条件下，Qwen3.5-9B 的模型选择未显示相对随机选择的平均性能优势。主指标差值及 95% 家族 bootstrap 区间均跨过零；实验完成不以结果必须为正为条件。

## 性能

主指标是任务平均 Balanced Accuracy，辅助是任务平均 Accuracy 与 Macro-F1。每个任务先合并完整测试预测；已知重复测量先按真实样本平均类别概率，再计算指标。每个任务等权。

| A0：LM 选模型／默认参数 | 114/114 | 66.35% | 70.63% | 65.10% |

A0/A1 的 LM 选择模型；A1 的参数由后端依据固定 Valid，在最多三套配置中选优。此结果不等同于检验 LM 直接推荐超参数。固定模型在两档预算上均由开发任务选定为线性 SVM。Portfolio 需比较多个模型，依据合并训练前的 Valid 选模型，其计算成本单列。

## 数据与协议

149 个候选完成来源与适用性登记，保留 129 个任务、剔除或暂不纳入 20 个。正式任务为 UCR 72、TabMini 20、高维生物 5、Raman 17；开发任务为 UCR 10、TabMini 5。原始来源、版本、许可信息、哈希、转换与排除原因见 audit/DATA_AUDIT.md、audit/task-audit.csv 和 audited_data_manifest.json。

全体保留任务共 315 个测试轮次，其中开发 35、正式 280。有可靠官方 Test 的任务保留官方 Test；其他任务轮流留出一组数据测试，按批准规则使用五组，Alzheimer 任务使用三组。每轮从剩余训练数据固定留出约 20% 做 Valid。Train 摘要只来自 Train；参数比较使用 Valid；Test 不进入 LM 选择或反馈。

固定处理为 zscore＋none；知识、记忆、诊断、反馈行动和预算展示关闭，硬预算与运行检查保留。seed 统一为 42。传统模型选定参数后合并 Train 与 Valid 重新训练；深度模型保留最低 Valid loss 的 checkpoint，不再合并训练。深度训练 FP32、batch size 8、最多 200 epochs、早停耐心 20。

缺少真实样本／受试者编号的任务按用户批准采用来源记录评测。此类成绩不能证明对新受试者的泛化；已知真实组始终整组划分。task_scope.csv 的 evaluation_units 是实际评测单位数，不把新增行号当作独立性证据。不同处理版本按共同任务家族汇总。

当前冻结版本的 LM 为 630 个流程、1,260 次真实请求、1,364,478 token，未知用量为 0。无 LM 的运行明确记录零请求与零 token。LM 请求累计等待约 39.72 分钟；该值是请求用时之和。当前冻结执行从启动到控制器完成的总壁钟时间为 8.70 小时（包含数据准备、开发、正式训练及报告收尾，不含更早尝试和最终交付），见 execution_wall_time.json。全部训练累计工作用时约 116.60 小时，CUDA 事件区间累计约 75.56 小时；这些累加值不等于并行实验总壁钟时间，CUDA 区间包含设备空闲间隔。各阶段、排队与总壁钟时间保留在运行遥测和报告中。

历史投入单独核账：早期失败、旧源码开发和连接检查共 1,738 次训练、315 次真实 LM 请求、503,080 token；不计入正式效果或完成率。包含这些历史投入的 Goal 工作目录可核对总量为 13,643 次训练、1,575 次真实 LM 请求、1,867,558 token。历史请求按 operation_id、尝试编号和实际开始时间去重，避免跨版本引用同一 Session 重复计费。详见 audit/historical-cost-reconciliation.json。

## 资源与记录

分类训练最多使用 GPU 1、2、3、5，Qwen 独立使用 GPU 4。CPU 线程分配峰值 32，无超额分配；每卡并发峰值 8。全时段设备观测平均利用率约 47.8%～57.5%，不是持续满载或内核活跃时间的声明；设备观测可能包含其他进程，作业分配计数只统计本调度器。

训练权重储存器已提交载荷历史峰值 166.07 MB；含初始预约和临时写入的保守上界 172.36 MB，低于 50,000,000,000 字节限制。累计清理约 6.656 GB，结束时无开放预约。保留 13 个模型的开发期代表束，来源可包含更早开发版本，不能用作冻结版本效果证据；保留对象及受保护状态见 audit/retained-weight-reconciliation.json。

本轮按用户明确批准跳过 SwanLab，以完整本地记录验收。recording-override.json 保存批准依据；没有宣称完成云端上传或回读。
