2026-10-10 用户批准首轮完整实验；2026-10-11 批准评价口径与目标提示修正；2026-10-12 明确要求全量重跑和持续迭代。当前执行协议为 `autoai-classification-benchmark-v5`，配置与变更依据在 `work/benchmark-20261012-full-v5/approval/`。已完成的 v4 配置和结果继续保留，以下首轮完成统计均指历史 v4；新 v5 结果尚未完整。科学配置变化仍须由用户明确批准并另行记录。

## 目的与范围

固定 zscore + none，seed 42，比较默认参数和包含默认配置的最多三套参数；Qwen3.5-9B 原始权重选择模型；最多三套参数由后端按固定 Valid 的 Balanced Accuracy 选优，先完成选择请求再训练。知识、记忆、诊断与预算展示关闭，硬预算和运行检查保留。固定模型只依据开发任务确定；Portfolio 依据 Valid。动态处理仅 Coffee 的两次功能验收，不进入正式效果结论。

有官方 Test 时保留它，其余训练数据约 20% 留作 Valid。无官方 Test 时按独立样本分五组轮流测试，每轮剩余数据约 20% 留作 Valid；类别不完整时仅允许已批准的三组规则，仍不合法则排除。传统模型选好配置后用 Train+Valid 重新训练；深度模型保留 Valid loss 最低的 checkpoint。三套候选之间统一依据 Valid Balanced Accuracy 选择。Test 不进入 LM 输入、选择和反馈。

主指标为任务平均 Balanced Accuracy，辅助为任务平均 Accuracy、Macro-F1。重复测量先按独立样本平均概率再算 Test 指标。任务等权，另报来源及任务家族、配对差值、胜平负、排名和家族 bootstrap 区间。不完整任务不能拼出完整成绩。
