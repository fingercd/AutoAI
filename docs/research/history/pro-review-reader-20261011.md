# 第一轮模型选择失败分析：给研究顾问的阅读说明

本包是对已冻结结果的只读、事后诊断，没有新增训练或 LM 选择实验，没有改变原协议。请独立核对事实和解释，不必认同执行者的初步假说。

## 研究目标与当前疑问

目标是在小样本、有限训练预算下，用 LM 做有用的建模决策，而不仅是执行固定流程。用户希望判断：当前负向平均差来自代码错误、数据/评测设置、输入和提示词、模型能力，还是方法本身；下一步应该先做什么。当前先不启用 memory，也不启用静态知识卡，以免混入新因素。

## 已确认的实际行为

- 正式评测 114 个任务，15 个开发任务用于验收及选固定模型；正式 280 个轮次，每预算各有 280 次模型选择。原始均值与 CI 见 results/REPORT_zh.md。
- A0/A1 只允许 LM 返回一个 model_id。LM 不生成训练代码、超参数或三套参数。
- 三套配置由 backend/app/benchmark_protocol.py 的固定表生成：默认先执行，其余合法配置按表顺序补足，最多三套；不是随机搜索。每套按 Valid BA 比较。深度每套内部按最低 Valid loss 保存 checkpoint。
- 固定 SVM 是在 15 个开发任务上从所有正式任务均合法的七种模型中按平均 BA 选出的固定算法；两档预算均选到线性 SVM。它不表示 SVM 是每个正式任务的最好模型，预算 3 仍允许按各任务 Valid 选 C。
- 请求包含每个合法模型的完整冻结 model_params；所谓 model_profiles 实际只有架构/策略版本号与成本描述，没有有意义的模型适用性介绍。A1 未把三套候选的实际参数值逐项提供给 LM。
- Train 证据主要是样本数、特征数、类别比例、重复测量/重复列/零方差风险；没有任务域或公共轴语义、原始曲线、线性可分性、相关性谱或模型试跑成绩。不能把“有 Train 摘要”当成信息足够。
- 实际 Qwen3.5-9B 请求全部 temperature=0、top_p=1、max_tokens=1024、enable_thinking=false。结束请求只允许 finalize_ml_session + 空 arguments；这一请求没有改变训练或模型选择的机会。
- 协议 knowledge=off、memory=off、feedback_diagnosis=off；630 个选择请求实际输入均不包含知识/记忆条目。此前“五条”是静态知识卡，非本轮积累记忆。

## 优先排查的实现/设计问题（尚未做干预验证）

1. **候选顺序是强混杂因素。** recipes.py:164 按 recipe_id 哈希排序。相同任务和轮次，A0/A1 的 Train 统计和默认参数映射全部相同（280/280），但候选排列全部变化（280/280），221/280 次改变选中模型。560 次正式选择中 427 次（76.25%）选了四个常见传统模型中出现最早的一种；列表首项被选 262 次（46.79%），均匀选择的期望约 10.64%。这是强关联，仍需只换顺序的受控诊断才能证明因果。
2. **提示词可能把合法性当作主要目标。** system 说 Select the permitted action / canonical model_id，没有明确要求比较归纳偏置并争取最高泛化 BA；大量理由只复述“该模型是合法候选”。请审阅全部真实输入输出，不凭一条例子下结论。
3. **可见评估配置与实际可信分区的语义不一致。** 真实请求 task.evaluation_config 仍展示 stratified_holdout 8:1:1，而实际数据按冻结的官方 Test 或轮流留出规则处理。此前执行审计验证的是实际分区正确；该陈旧展示字段是否误导 LM 尚待诊断。
4. **不是对 LM 提参数的检验。** 三套候选后端固定，选择阶段没有候选逐项数值；仅扩大训练预算同时重新选模型，不能把所有变化归因于 HPO。
5. **小样本定位需要说清。** 正式数据中 16 个任务至少一轮 Train 的 sample_group_count 超过 500，最大 7,141；部分 Raman 的 group 是来源记录，不能当真实独立受试者数。请区分小样本子集和全体任务，不建议根据效果事后排除任务。
6. **当前没有发现矩阵或指标算错。** 新脚本从全部正式预测重新构建各任务的混淆计数，复现 A0/A1 BA，精确对齐任务和模型的差值贡献。此前训练配置、候选缓存、预测/产物和 LM 绑定全量审计在 evidence/。这些不能排除模型实现、预处理轴或训练优化本身的不足，需结合冻结源码检查。

## 各模型谁最好：比较必须保持同一任务集

analysis/model_performance_by_suite.csv 给出完整域内模型比较；analysis/model_means_common89.csv 将所有 13 模型放在共同 89 个有自然顺序任务上比较。全 114 任务均合法的七模型中，默认预算平均 BA 最高是 Logistic Regression 68.22%；预算 3 最高是 Random Forest 70.72%。在共同 89 项上，Inception1D 两档分别 72.33%/73.03%，但是 LM 两档仅选 0/1 次。不能直接拿 89 项均值与 114 项均值比较。按域：时序 Inception1D 较高，普通表格 Random Forest 较高，五个基因及 17 个光谱 SVM 较高；全表保留所有模型，不只给赢家。
