## 当前结论

在同一批129个任务、七种模型的903项同条件成绩上，最初知识选择的平均平衡准确率为69.2747%，修订优势知识后为71.5062%，同七模型均匀随机期望为65.0502%。修订版比随机高6.4560个百分点，比初版高2.2315个百分点。

这是支持继续研究先验辅助选模的内部可行性证据，不是独立泛化或知识单独贡献的证明：知识整理使用过这些任务的成绩；新旧知识之间还同时增加了两个训练描述。旧的全量实验与当前七模型单次验证在任务范围、模型菜单、样本安排与输入方面不同，不能直接充当同条件“无知识”消融。

主要未解决问题：修订版81个时序任务选择卷积，25个表格全部选择逻辑回归，5个基因表达全部选择偏最小二乘；主成分降维加线性判别仍为0次。基因表达平均成绩由81.2988%降至73.5614%，不能只报告整体改善。
