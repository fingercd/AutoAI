# 参考分层知识选模型与均匀随机选择的内部验证结果

日期：2026年10月14日。知识内容于前一阶段经用户确认；本日用户另行批准仅明确JSON输出结构及首任务的一次必要格式重试。

这是同一批任务上整理经验后再回看的探索性结果，不是独立测试上的泛化结论。没有额外的无知识大模型对照，因此也不能单独证明这部分差值全部由知识带来。

### 选择理由不能直接当作可靠诊断

部分理由使用了笼统的“稳健”“避免过拟合”等描述，并没有清楚解释为何覆盖了检索卡中的其他推荐。例如医学图像时序任务在多类别与严重不平衡条件下选择随机森林，但对应数理知识的重点是逻辑回归、梯度提升树和支持向量机。推荐不是硬约束，因此不能仅凭这一点判定它违反规则；但可见理由没有充分说明这种取舍。

另一个具体问题是小型厨房电器时序任务：训练画像有300个训练分组、720个特征、有效维数约82.20，只匹配类型经验；回复却称“样本量极小且特征高度冗余”。这至少不是对已确认“小样本不超过50”和“有效维数不超过3”经验条件的忠实复述。其逻辑回归成绩为41.07%，随机期望56.11%。本轮没有根据这些理由或成绩再次调用大模型改选。

## 结果能说明什么，不能说明什么

- 可以说明：这次参考已确认分层经验的选模流程，在同129任务、同七模型默认成绩上，比均匀随机期望平均高4.22个百分点。
- 不能说明：该差值可在新的独立任务、新受试者或不同来源数据上复现。知识归纳和评价复用了同一批任务及成绩；删除任务名称和直接测试分数没有消除所有间接数据复用。
- 不能单独归因于知识：按用户要求，没有另加无知识大模型组，因此未隔离知识与大模型既有偏好的贡献。
- 不能认为每个任务都更好：41个任务低于随机期望，模型使用也明显偏向四种传统模型。
- 不能宣称高效液相色谱专项效果：本轮没有单独登记的该专项任务集合。

不覆盖旧实验，不修改已确认知识，不追加第二轮选择、模型集成、参数搜索或分类重训。没有提交、推送或生产部署。
