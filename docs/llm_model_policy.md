# Agent 推理模型策略

2026-09-30 按用户确认和服务器实际资产登记三项：Qwen3.5-9B、Qwen3.5-27B、Qwen3.8-27B。它们分别使用 `qwen35_9b`、`qwen35_27b`、`qwen38_27b` 服务 ID。当前没有 Qwen3.8-9B 资产，不虚构第二个 9B。

`agent_poc/config/models.toml` 是唯一允许目录，保存真实原始/W8A8 权重路径和历史端点。模型文件存在不等于服务在线；新实验须核对所选节点、GPU、进程、端点和实际加载路径，不能仅信任 `/models` 的名称。

`LLMConfig` 在网络请求和任务副作用之前拒绝目录外的 LLM；验收脚本没有 4B 默认模型，恢复验收也必须显式提供服务和模型。没有可用批准服务时不运行真实 LLM 实验，不做 4B/8B 回退。

当前用户明确指定其他型号时，可以同时传入 `--llm-model <用户指定的服务ID>` 与 `--allow-unapproved-llm`。不从环境变量开启例外；显式命令中的模型参数不可省略。程序调用对应 `allow_unapproved_model=True`。例外写入 LLM 冻结配置，改变指纹；旧未完成任务不能借此无声恢复。这个参数本身不授予人类授权。

4B 历史状态可通过只读 status/export 查看；日志与模型文件不删除，旧 4B 验收服务停止并禁用启动入口。离线 scripted provider 夹具可使用明确的测试例外，不发送真实模型请求。
