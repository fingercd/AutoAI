# AutoAI 分类研究助手

告诉 Agent 要处理的文件和目标即可。它会读取 Excel/CSV 或原始曲线，说明数据情况，推荐模型与训练设置，并完成分类训练和结果交付。

## 怎么使用

> 使用 $autoai-research 对 D:\PythonProject\AutoAI\测试.csv 做分类，推荐一个快速方案并运行。不要反复问我。

> 使用 $autoai-research 整理这份拉曼 Excel 并建模。同一样品测了三次，请保留这个分组；确实缺少的信息一次问完。

> 使用 $autoai-research 处理这些 HPLC 文件。标签和样品分组在附件里，处理后比较我指定的两个模型。

助手先说明“文件是什么、建议怎么做、有什么确实需要确认”。需要回答的问题会集中在一轮里；回答后直接训练。已经明确要求直接运行的任务，按现有信息和推荐设置执行，并告知所选模型和参数。

完成后提供模型、实际设置、测试成绩、需要注意的问题和可下载文件。原始数据始终保留。缺失标签、真实样品分组不清楚等问题不能靠猜测补齐，会一次指出需要补充的信息。

## 安装与维护

本机 Skill 已安装到 Codex 的用户技能目录。开发源在 `skills/autoai-research`，修改后同步安装副本。首次在其他设备使用时，由部署维护者提供可用运行环境；研究使用者不需要操作内部接口或填写系统编号。

助手会自动检查并准备本地计算环境。详细运行方式、文件映射和维护命令放在 Skill 的内部参考材料中，供 Agent 执行与排障使用。

用户指定的文件、转换过程、训练设置和结果会保存在独立实验目录。恢复计算时保留该目录，告诉助手继续已有实验即可。
