# AutoAI 分类研究 Skill 使用说明

首版用于在 Codex 等具备文件读取、Python 执行和网络访问能力的 Agent 中完成拉曼/HPLC 分类实验。用户可以交付 Excel、CSV 或当前预处理支持的原始曲线，用对话确认数据含义、选择处理方式，并由 Agent 推荐模型。

## 安装与连接

1. 安装并启动本仓库的后端版本：`python run_classic.py`。默认服务为 `http://127.0.0.1:8000`，启动器同时监督 Worker；已有服务不重复启动。
2. 将仓库 `skills/autoai-research` 整个目录复制到宿主 Agent 的技能目录。Codex 用户目录通常为 `~/.codex/skills/autoai-research`；仓库目录是维护源，修改后需要更新安装副本。
3. Agent 执行脚本的 Python 环境安装 `httpx openpyxl swanlab`。SwanLab 使用已有登录或安全注入的凭据，不重复清除/重建认证。
4. 远端个人服务设置 `AUTOAI_SERVICE_URL`，并安全注入 `AUTOAI_SERVICE_TOKEN`；SSH 隧道也可连接本机回环地址。不要把一个身份令牌当作多人账号系统。

后端必须支持新增预检与幂等接口，旧服务会在预检时报错。技能目录不包含模型、数据或后端安装包；客户端通过 HTTP 调用后端，不导入仓库运行代码。

## 提问示例

> 使用 $autoai-research 检查这份拉曼 Excel。同一样品有三次重复测量，请先确认格式，再推荐一个快速分类基线并直接运行。

> 这些 HPLC 文件需要按固定轴插值。标签和样品分组在附件映射表里，请检查点数和时间范围，再比较我指定的两个模型。

> 恢复 outputs/my-experiment 里的训练，查看结果，不要重复启动实验。

Agent 只询问尚不明确的标签、样品分组、工作表关系和处理要求。模型由 Agent 根据真实数据及可用能力推荐；默认快速、全特征、标准化和 seed=42，用户可要求多模型、完整比较或留一法。

## 文件与恢复

每次实验使用独立输出目录，保存来源副本、映射、转换报告、state.json、预检、结果及 SwanLab 本地事件。目录中的状态是恢复依据，应与结果一起保留。转换不会覆盖原文件，也不会自动填缺失值、复制测量或拆散重复样品。

训练提交超时后用同目录 submit 恢复，或已有 ID 时 status/watch 查询。新实验用新目录。会话结束不停止后端训练；恢复后可以补齐最终结果。SwanLab 上传失败保留本地事件，用 sync-cloud 补传，交付前查看核验状态。

详细映射和命令见 Skill 内的 references。普通临床指标表、回归、不一致重复次数的数据尚不属于首版可自动训练范围；系统会给出具体限制。
