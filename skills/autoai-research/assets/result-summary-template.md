# 分类实验结果

根据 summary.json 和经过校验的结果填写，删除不适用项。

- 数据：原文件、转换记录、独立样品数、测量条数、类别及真实坐标范围。
- 方案：模型推荐理由、实际模型/版本/profile/特征方案/标准化/seed。
- 评估：模式、实际分组划分；主指标来自 direct Test、external Test 或 pooled OOF。
- 结果：Accuracy、Balanced Accuracy、Macro-F1、Weighted-F1，以及必要的逐类指标。
- 限制：警告、失败或未运行方案、缺失产物；说明合成数据或真实数据及 Test 是否参与后续选择。
- 追溯：Dataset/Run/Batch ID、代码版本、任务目录、SwanLab 链接及核验状态。
- 文件：经典结果页、转换报告、公开结果文件和可用预测导出。

缺少的字段写明原因，不填零。训练完成不等于性能充分验证。普通留一法展示逐折配置，不编造全局最佳配置。
