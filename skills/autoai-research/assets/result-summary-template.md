# 分类结果摘要

根据实际结果填写，保持简洁，删除不适用项。用户没询问的运行细节留在实验记录中。

1. **完成情况**：是否训练完成，使用了哪份文件，实际模型是什么。
2. **实际方案**：特征处理、标准化、实际训练/验证/测试样品数，以及最后选定的模型参数。普通用户不必阅读原始配置。
3. **测试表现**：准确率、平衡准确率、Macro-F1，以及具体值得注意的类别表现。说明成绩来自保留测试样品还是逐个留出样品的合并预测。
4. **研究限制**：例如测试样品太少、某类别识别较差；只列会影响结果解读的具体问题。
5. **文件**：预测表、结果摘要、可用图表和结果页面，提供可点击链接。

内部编号、连接检查、执行组件、接口地址和恢复命令不作为默认摘要。用户询问复现或故障细节时，再读取相应记录解释。

没有生成的结果说明原因，不填零。普通留一法没有统一最佳参数，应按折说明。训练完成不等于已充分验证预测性能。
