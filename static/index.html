使用手册

一、拉曼数据预处理

上传多个拉曼 CSV 后，可以按行号范围截取，也可以按 X 轴数值范围截取。X 轴通常是拉曼位移。系统会导出统一格式 CSV：Index、Name、XXX、Intensity、Label、Repeat_index。

基线校正顺序有两种：

方式处理流程适合情况
先选数据范围，后基线预处理 先截取目标行范围，只对截取后的片段做 baseline 校正。 只关心某个目标区间，希望区间外强峰不影响校正。
先基线预处理，后选数据范围 先对整条原始光谱做 baseline 校正，再截取目标行范围。 希望基线估计利用完整光谱的整体背景趋势。

二、色谱数据预处理

上传多个色谱 CSV 后，可以按行号范围截取，也可以按 X 轴数值范围截取。X 轴通常是 Time。系统默认第一列为 Time，第二列为 Intensity，并整理为统一建模格式。

三、AI 建模

进入 AI 建模页面后，可以直接加载项目根目录的 data.csv，也可以上传已经补充 Label 的统一格式 CSV。设置 epoch、batch size、学习率、标准化和划分方式后点击开始训练。

Repeat_index 整组划分：训练、验证、测试集不是按单条曲线随机划分，而是按 Repeat_index 整组划分。同一个 Repeat_index 下的重复测量会全部进入同一个集合，避免同一样品同时出现在训练集和测试集里造成指标虚高。

建模 CSV 中同一个 Repeat_index 只能对应一个 Label，且每组重复测量次数应保持一致。默认比例为 train : valid : test = 8 : 1 : 1。例如 10 个 Repeat_index、每组 5 条时，会划分为 train 8 组、valid 1 组、test 1 组。

如果样品组数较少，默认 8/1/1 可能让 valid 或 test 只有一个类别，指标会更容易波动。遇到这种情况，建议改成 6/2/2 或 7/2/1，让验证集和测试集包含更多 Repeat_index 分组。

四、结果下载

训练成功后，可下载 predictions.csv、metrics.json 和模型文件。深度学习模型为 model.pt，传统机器学习模型为 model.pkl。predictions.csv 包含 train、valid、test 的真实标签、预测标签和各类别概率。
