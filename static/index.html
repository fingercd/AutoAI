全局使用说明

各功能页顶部都提供与当前操作直接相关的简短说明。这里仅保留跨页面规则和故障排查入口。

统一数据格式

建模 CSV 固定使用 Index、Name、XXX、Intensity、Label、Sample_ID 六列。Label 始终按分类类别处理；相同 Sample_ID 会整组划分，避免重复测量泄漏到不同集合。

训练与结果

提交训练只会创建排队任务，独立 worker 负责执行。完成后使用唯一 Run ID 进入建模结果；结果页刷新或服务重启后仍可重新获取。

服务器访问

服务器模式会要求访问令牌。令牌仅保存在当前标签页会话存储中，不写入 URL、本地持久存储或下载文件。
